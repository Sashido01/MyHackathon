# IT Sprint 2026 · Team Project

**Открытый командный проект регионального кейс-чемпионата «ИТ-спринт».**

**Status / Статус:** подготовка репозитория; кейс ещё не назначен; продукт не реализован.

> **English summary:** Public repository for a three-person team participating in IT Sprint 2026, a regional industry case championship. The case and technical requirements are not yet assigned. This repository will contain the implemented solution, reproducible setup instructions, design decisions, tests, and evidence of individual contributions.

## О проекте

В рамках чемпионата команда из **3 участников** получит один из кейсов компаний «Русагро», «Пятый элемент», «ВымпелКом» (Билайн) или «Школа 21». До выдачи технического задания мы не утверждаем, что знаем требования будущего продукта.

**Сроки по информации о мероприятии, переданной команде:** дистанционный этап — **12–29 октября 2026**, очный этап — **20 ноября 2026**. Условия и порядок проведения необходимо сверять с официальным положением.

## Разработка

Проект будет разрабатываться публично: с понятными задачами, проверяемыми изменениями и историей решений. Пока код отсутствует, инструкции по сборке и запуску добавлять преждевременно. После получения кейса здесь появятся требования, краткое описание решения, запуск, тесты и материалы демонстрации. Базовые проверки репозитория запускаются автоматически через GitHub Actions; они не являются тестами будущего приложения.

Для работы с исходным кодом используется GitHub-репозиторий [`Sashido01/MyHackathon`](https://github.com/Sashido01/MyHackathon). У владельца репозитория локальная рабочая папка — `D:\MyHackathon`; у других участников пути могут отличаться.

## Команда и вклад

Команда состоит из **трёх человек**. Профили и фактический вклад будем указывать по мере подтверждения в [AUTHORS.md](AUTHORS.md) и истории Pull Requests. Пока роли не распределены.

## Лицензия и права

**Открытая лицензия пока не предоставлена.** Публичный доступ к репозиторию не равнозначен разрешению свободно копировать, изменять или распространять код. Перед размещением решения и материалов кейсодателя команда проверит правила чемпионата, допустимость публикации и согласие правообладателей. Подробности — в [docs/licensing.md](docs/licensing.md).
