# Кроссплатформенность: Windows и Ubuntu 24.04

**Целевая среда финальной очной демонстрации:** ноутбук с Ubuntu 24.04 LTS. Разработка ведётся на нескольких компьютерах под Windows и Linux. Конкретный кейс, технологический стек и способ запуска приложения ещё не определены.

## Принципы

- GitHub `main` — единый источник отслеживаемого исходного кода; изменения проходят через PR и обязательные проверки.
- Пути не зашиваются в приложение: на Windows рабочая копия владельца находится в `D:\MyHackathon`, на Ubuntu — в выбранной пользователем папке, например `~/MyHackathon`.
- В репозитории для текстовых файлов действует LF (см. `.gitattributes`). Настройка Git `core.autocrlf=false` применяется только локально в каждом клоне.
- Команды сборки и запуска после назначения кейса должны быть документированы для обеих ОС либо явно обозначена целевая платформа.
- Не требовать локальных административных прав или постоянного доступа к сети без необходимости. При необходимости таких прав/сети описывать причину.
- Не хранить секреты, персональные или ограниченные кейсодателем данные в репозитории. Для конфигурации — шаблоны без секретов.
- Проверка в GitHub Actions на Ubuntu **не заменяет** запуск на физическом ноутбуке с Ubuntu 24.04.

## Базовая проверка на Windows (PowerShell 7)

```powershell
git -C D:\MyHackathon switch main
git -C D:\MyHackathon pull --ff-only origin main
Set-Location D:\MyHackathon
git config --local core.autocrlf false
python --version
python scripts/check_repo.py
python -m unittest discover -s scripts/tests -v
git status --short
```

## Базовая проверка на Ubuntu 24.04 (терминал)

Нужны Git и Python 3.11+ для текущих проверок репозитория. На Ubuntu 24.04 обычно доступен Python 3.12; проверить наличие инструментов можно командами `git --version` и `python3 --version`.

```bash
# Для первого клонирования (если папки ещё нет):
git clone https://github.com/Sashido01/MyHackathon.git ~/MyHackathon
cd ~/MyHackathon

git config --local core.autocrlf false
python3 scripts/check_repo.py
python3 -m unittest discover -s scripts/tests -v
git status --short
```

Если репозиторий **уже клонирован**, не клонируйте его снова: выполните `cd ~/MyHackathon`, затем `git switch main && git pull --ff-only origin main` при чистой рабочей копии.

При отсутствии Git или Python их установку следует согласовать с владельцем ноутбука. Для стандартной Ubuntu 24.04 с доступом к пакетным репозиториям допустима установка `sudo apt update && sudo apt install git python3` — **только при необходимости**. Это не зависимости приложения.

## До утверждения технологий

Мы не фиксируем Docker, Node.js, Python-фреймворк, базу данных или LLM-провайдера заранее. После назначения кейса зафиксировать версии зависимостей, команды установки, запуска, проверки и очистки для Ubuntu 24.04; Windows поддерживать там, где это не противоречит ТЗ. Для Docker предусмотреть автоматическое восстановление после перезапуска ноутбука только при реальной необходимости.
