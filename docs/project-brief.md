# Паспорт проекта / Project brief

_Обновлено: 9 октября 2026 года. Исходные сведения о мероприятии предоставлены участником команды; полное положение и техническое задание пока не приложены._

## Известные вводные

- Мероприятие: региональный кейс-чемпионат «ИТ-спринт».
- Команда: **3 человека**, без формального распределения ролей на данном этапе.
- Дистанционный этап: **12–29 октября 2026**.
- Очный этап: **20 ноября 2026**.
- Возможные кейсодатели: **Русагро**, **Пятый элемент**, **ВымпелКом (Билайн)**, **Школа 21**.
- Команда получит один кейс; **какой именно — неизвестно**.

## Пока неизвестно

- Официальное техническое задание и обязательные функции.
- Критерии оценки и допустимость использования готовых решений и ИИ.
- Условия публикации кода, данных и материалов кейсодателя.
- Права на результаты, допустимость открытой лицензии.
- Ограничения на технологии, хостинг, внешние API, бюджеты.
- Формат итоговой поставки, демонстрации и защиты.

## Первый день после получения кейса

1. Зафиксировать исходное ТЗ и ссылку/версию документа с учётом прав на публикацию.
2. Сформулировать задачу пользователя и критерии приёмки.
3. Разделить функции на обязательный MVP и дополнительные.
4. Проверить риски, доступность данных, внешних сервисов и сроков.
5. Выбрать стек только по требованиям кейса; задокументировать решение (ADR).
6. Добавить команды воспроизводимого запуска, тесты, затем CI.

## Цель открытого репозитория

Показать проверяемый результат и ход инженерной работы: решение реальной проблемы, понятную структуру, воспроизводимый запуск, качественные проверки и подтверждённый вклад участников. Сам факт наличия документов ещё не означает, что эти цели достигнуты.
